# ha-telegram-bot-extended

Additional functionality for the native `telegram_bot` integration of Home Assistant.

## Installation

### HACS (recommended)

1. Open HACS in Home Assistant.
2. Add this repository as a custom repository with type **Integration**.
3. Search for **Telegram Bot Extended** and install it.
4. Restart Home Assistant.

## Repository structure

- `custom_components/telegram_bot_extended/` - Home Assistant custom integration package.
- `hacs.json` - HACS/Home Assistant Marketplace metadata.
